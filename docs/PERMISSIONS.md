# 權限

| 能力 | 業者 | 承辦 | 管理員 |
|---|---|---|---|
| 維護自己的業者資料 | 是 | 否 | 否 |
| 建立與編輯自己的草稿／補件 | 是 | 否 | 否 |
| 查看案件 | 同組織 | 只看派給自己的 | 全部 |
| 派案 | 否 | 否 | 是 |
| 初審、複審、要求補件 | 否 | 被指派時 | 是 |
| 核定、退件、待核定補件 | 否 | 否 | 是 |
| 課程與出席 | 報名自己的 | 是 | 是 |
| 內部帳號、匯入、稽核 | 否 | 否 | 是 |

跨組織或未派給該承辦的案件，API 回 404，不回 403，避免用狀態碼確認資料存在。業者看到的歷程不含 `internalNote`。

停用帳號後，既有 session 在下一次要求時拒絕。最後一位啟用中的管理員不能被停用或降級。
