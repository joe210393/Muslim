# 待確認事項

這些項目沒有正式資料。程式使用標成示範的內容，不把示範名稱當成正式類別。

| 項目 | 目前假設 | 正式上線影響 |
|---|---|---|
| 七類申請表 | 類別名稱與新表單版本依 2026 年空白申請表。`CAT_01` 到 `CAT_07` 依序是餐廳三選一、食用品、旅宿、商店、旅行社、環境、體驗活動。新草稿用已確認版本；舊案件維持原本的示範版本 | 食用品的申請項目格子是空的，名稱用表頭。類別排序不是空白表上的官方序號。教育時數仍沒有寫在表上 |
| 第 1 類舊版 | 第 1、2 版仍是示範欄位，只留在已建立的舊案件 | 不把舊案件改到新表單 |
| 統一編號 | 空白申請表寫無則免填。有填仍暫定 8 位數字；海外規則未定 | 不能把 8 碼當成正式統編檢查 |
| 完課門檻 | 線下仍以出席分鐘計算。線上課程改為看完上傳影片時間的三分之二才算通過。教育時數不擋案件核定 | 若業主要求先上課才能送件，需另開工單 |
| 課程回饋 | 教育訓練列表有這個欄，目前不能填 | 正式回饋表未提供，欄位先標尚未開放 |
| 證書 | 管理員在核定後人工登錄編號與日期 | 沒有自動發證。合約 PDF 是另一份簽署檔 |
| 聯絡窗口 | `contact@example.test` | 需換成正式窗口後才能公開 |
| 郵件、簡訊、LINE | 主控台郵件標為 `MOCKED`，不標 `SENT` | 正式 SMTP 尚未申請 |
| 備份 | 文件說明手動 `pg_dump` 與 Volume | 沒有排程，不能當成已備份 |
| 前台文案、FAQ、消息 | 首頁 Hero／Banner 由內容管理寫入資料庫。其餘初稿在 `apps/web/src/content/site-content.ts` | 正式稿可在後台覆蓋首頁，其餘仍替換該檔 |

| 現場複審檢查表 | 七類檢查項目依 2026 年兩份檢查表。餐廳用餐點及廚房、食用品用食品、旅宿用旅館及民宿、商店用商店、旅行社用旅行社、環境用友善環境、體驗活動用體驗活動。檔名寫商品，表內這一節是商店。檢查表標題寫食品，申請表標題寫食用品 | 現場複審對送件附件點通過或沒通過，存在 `site_checks`。檢查表照片可再上傳現場拍攝，`captured_on_site` 為真，不取代業者原照。錄影規則未見於檢查表 |
