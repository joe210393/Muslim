# 待確認事項

這些項目沒有正式資料。程式使用標成示範的內容，不把示範名稱當成正式類別。

| 項目 | 目前假設 | 正式上線影響 |
|---|---|---|
| 七類正式名稱與審查表 | `CAT_01` 顯示「第 1 類：廚房／餐廳相關（名稱待確認）」；其餘為「第 N 類（待提供正式名稱）」。`configurationStatus` 為 `DEMO` | 未確認前，正式環境 `DEMO_MODE=false` 會拒絕用這些類別送件 |
| 第 1 類第 2 版 | 多一個 `serviceHoursNote`，只供示範舊案不自動改版 | 正式欄位待業主提供後另建 form version |
| 統一編號 | 暫定 8 位數字；海外或無統編規則未定 | 不能直接當正式驗證規則 |
| 完課門檻 | 以課程分鐘數的門檻計算，教育時數不擋案件核定 | 若業主要求先上課才能送件，需另開工單 |
| 證書 | 管理員在核定後人工登錄編號與日期 | 沒有自動發證、PDF 套版或電子簽章 |
| 聯絡窗口 | `contact@example.test` | 需換成正式窗口後才能公開 |
| 郵件、簡訊、LINE | 主控台郵件標為 `MOCKED`，不標 `SENT` | 正式 SMTP 尚未申請 |
| 備份 | 文件說明手動 `pg_dump` 與 Volume | 沒有排程，不能當成已備份 |
