# 待確認事項

這些項目沒有正式資料。程式使用標成示範的內容，不把示範名稱當成正式類別。

| 項目 | 目前假設 | 正式上線影響 |
|---|---|---|
| 七類申請表 | 類別名稱依七個資料夾：穆斯林友善餐廳、旅宿、環境、體驗活動、商店、旅行社、產品。類別決定證書用哪一類。餐廳、旅宿、環境、體驗活動、商店的新草稿用勾選決定附件；旅行社與產品仍用各自申請表。舊案件維持原本表單版本 | 產品資料夾的申請表標題仍是食用品。旅行社與產品沒有出現在場域勾選表。教育時數仍沒有寫在表上 |
| 第 1 類舊版 | 第 1、2 版仍是示範欄位，只留在已建立的舊案件 | 不把舊案件改到新表單 |
| 統一編號 | 空白申請表寫無則免填。有填仍暫定 8 位數字；海外規則未定 | 不能把 8 碼當成正式統編檢查 |
| 完課門檻 | 線下仍以出席分鐘計算。線上課程改為看完上傳影片時間的三分之二才算通過 | 一般課時數仍不擋案件核定 |
| 基礎教育訓練 | 帳號開通後須完成示範基礎課（標題／YouTube／需觀看百分比／教材，可多門）與題庫抽題測驗，才可建立／送出驗證申請。觀看達設定百分比後由系統標示完成，不可自行點完成。測驗通過只在教育訓練顯示「已完成」，不發證書。證書僅線上／線下課程與專班完課後由承辦人工登錄。抽題數、及格題數、是否擋申請、專班最低人數由後台「門檻設定」可改。題庫以後台表單新增／編輯為主，檔案匯入為進階選項 | 正式教材、題庫內容、各課正式觀看百分比待甲方提供後替換 |
| 訓練證書 | 基礎課通過後自動產 PDF。一般線上／線下課由管理員對完課報名人工登錄編號與效期 | 自動證效力、一般課是否也要自動證待確認 |
| 業者專班申請 | 人數達門檻才可送出，管理員核准或退回；初版核准後不自動建課，可選填對應課程 | 費用、場地與開課流程待確認 |
| 課程回饋 | 教育訓練列表有這個欄，目前不能填 | 正式回饋表未提供，欄位先標尚未開放 |
| 證書 | 管理員在核定後人工登錄編號與日期 | 沒有自動發證。合約 PDF 是另一份簽署檔 |
| 聯絡窗口 | `contact@example.test` | 需換成正式窗口後才能公開 |
| 郵件、簡訊、LINE | 主控台郵件標為 `MOCKED`，不標 `SENT` | 正式 SMTP 尚未申請 |
| 備份 | 文件說明手動 `pg_dump` 與 Volume | 沒有排程，不能當成已備份 |
| 前台文案、FAQ、消息 | 首頁 Hero／Banner 由內容管理寫入資料庫。其餘初稿在 `apps/web/src/content/site-content.ts` | 正式稿可在後台覆蓋首頁，其餘仍替換該檔 |
| 費用與金流 | 方案金額可建立。結帳走綠界全方位金流測試商店，付款通知檢查碼正確且不是模擬付款才改成已付款。公開費用表金額仍是「待填」 | 甲方註冊後改 ECPAY 環境變數。正式環境沒有商店金鑰時不能結帳 |
| 朝拜時間表 | 只留欄位，不填推測時間 | 需甲方提供資料來源 |
| 現場複審檢查表 | 紙本檢查項目仍依 2026 年兩份檢查表對照。系統改為：業者只上傳送件附件；複審以同一批附件核對通過／沒通過，必要時可選現場拍照存證 | 現場結果在 `site_checks`。現場照片 `captured_on_site` 掛在送件附件項，不取代業者原照。業者申請端不再上傳檢查表照片。錄影規則未見於檢查表 |
| 合約、續約、授權資源 | 示範合約可簽署並下載 PDF。業者可把已簽署合約登記為已續約或未續約。法律效力、費用與是否重新現場複審未定 | 後台可新增範本與版本。已發出的合約不能再改內文。正式法律文字仍待貼上 |
| 個別權限勾選 | 三種角色的功能開關已可儲存並擋下對應 API | 若要改成每人一組權限，需另開工單 |
